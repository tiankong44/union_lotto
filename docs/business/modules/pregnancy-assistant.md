# 孕期助手模块

# 模块基本信息
- 模块编码：`pregnancy-assistant`
- 模块名称：孕期助手
- 所属业务域：孕期健康记录
- 负责人：待补充
- 当前版本：v1
- 更新时间：2026-08-06
- 依赖模块：胎动记录、孕期健康记录、产检待办、提醒同步

# 业务定位 & 作用
- 模块职责：提供个人孕期信息、健康记录、时间线、统计和同步入口。
- 解决的问题：将分散的孕期记录集中保存，并支持手机、平板和电脑查看。
- 不做会怎样：用户难以连续回看自身记录，也难以整理就医沟通资料。
- 目标用户/使用角色：孕妇本人，首版只有一个使用者。

# 核心业务流程
1. 前置条件：用户首次进入工具，浏览器可用本地存储。
2. 主流程步骤 1：建立或更新孕期档案，录入末次月经日或预产期等信息。
3. 主流程步骤 2：用户记录胎动、宫缩、体重血压、症状和产检事项。
4. 主流程步骤 3：数据先保存到本地，联网后进入后台同步队列。
5. 分支流程：用户查看历史、统计、个人趋势、时间线、导出或设置提醒。
6. 异常流程：网络失败保留本地记录并标记待同步；明显变化只提示联系产科。
7. 流程结果：形成可查询、可统计、可导出的个人孕期记录。

# 功能清单
- 孕期档案：待产期、孕周、胎儿数量、备注。
- 记录中心：胎动、宫缩、体重血压、症状、产检和待办。
- 查看功能：日历、时间线、单日详情和历史筛选。
- 统计分析：次数、时长、强度、个人趋势、记录完整度。
- 辅助能力：提醒、离线记录、后台同步、导出和设置。

# 原始业务需求
- 业务方原话：新增一个 Vite+Vue 前端项目，用来记录孕期胎动，并完善查看、统计、分析、后端和数据库。
- 需求背景：现有工具后端没有孕期记录模型和前端入口。
- 用户角色：单一使用者。
- 业务目标：提供跨电脑、手机、iPad 的响应式孕期记录工具。
- 提出时间：2026-08-06。

# 业务规则 & 约束
- 状态流转规则：本地记录依次经历本地保存、待同步、同步中、已同步或同步失败。
- 金额 / 数量规则：涉及数值字段的有效范围和单位仍需结合医疗业务确认，超出范围时拒绝保存并提示用户。
- 时间规则：记录时间使用用户本地时区保存展示，服务端保存可追溯时间。
- 权限规则：第一版只有一个使用者，不提供账号、用户隔离和共享权限。
- 禁止事项：不输出疾病诊断，不使用统一次数阈值替代医生建议，不把提醒当作医疗结论。
- 补充约束：数据删除、保存期限、跨设备恢复策略待补充。
