# 历史记录分类图表设计

## 目标

在历史记录页为胎动、宫缩、健康和待办四类记录提供分类图表查看入口。图表只描述单用户已保存的历史记录，不新增医疗判断、提醒阈值或后端数据契约。

## 用户交互

- 历史记录工具栏保留四类分类切换，并增加图表图标按钮。
- 点击按钮后，在当前分类列表上方展开图表；再次点击收起。
- 切换分类时自动收起图表，避免上一分类的图表内容残留。
- 图表支持最近 7 天、30 天和 90 天，默认显示最近 30 天。
- 图表数据继续复用当前 Pinia 已加载数据，不触发额外请求。
- 图表按钮提供 `title`、`aria-label`、`aria-expanded` 和键盘可操作状态。

## 数据口径

- 胎动：按用户本地自然日统计胎动总次数和会话数。
- 宫缩：按用户本地自然日统计记录次数、平均持续秒数和平均间隔秒数；缺少间隔的记录不参与平均间隔计算。
- 健康：体重按自然日取当天最后一条有效记录；血压按自然日取当天最后一条有效高压/低压记录；症状按有效日期统计记录数。
- 待办：按 `plannedAt` 日期和当前 `status` 统计待处理与已完成数量，不模拟历史状态变化。
- 非法日期或非法数值只跳过对应图表点，不能阻断原有历史列表展示。
- 没有有效数据时展示图表空态，列表和备注、删除操作保持可用。

## 实现边界

- 新增 `RecordChartPanel.vue` 作为图表业务组件，接收当前分类与四类记录数组。
- `RecordsView.vue` 只负责图表开关、当前分类和图表组件挂载，不改变原有记录编辑、备注和删除流程。
- 图表使用现有 Vue、TypeScript、Lucide 图标和原生 SVG/CSS，不引入新的图表依赖。
- 不修改 Java Controller、Service、Mapper、SQL、HTTP API 或路由。

## 异常与验收

- 空数据、非法日期、非法健康 JSON 不应导致组件渲染异常。
- 图表时间范围切换后，所有指标和空态必须同步更新。
- 窄屏下图表允许横向滚动，但历史列表的操作区不能被遮挡或溢出。
- 完成 `npm run type-check` 和 `npm run build`，并通过源码静态检查。
- 不进行真实数据库写入联调，不使用浏览器截图或视觉辅助，不编写单元测试。
